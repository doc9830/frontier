# FRONTIER для Android

Оболочка вокруг игры: WebView на весь экран плюс собственный апдейтер, который
берёт релизы из GitHub, не открывая браузер. Игра при этом лежит в APK, поэтому
приложение работает без интернета с первого запуска.

## Как это устроено

```
MainActivity ── WebView (https://appassets.androidplatform.net)
   │              ├── assets/www          — игра, вшитая в APK
   │              └── filesDir/www        — скачанное обновление игры (приоритетнее)
   ├── Bridge (window.FrontierAndroid)    — единственный вход из игры в оболочку
   └── Updater ── api.github.com → релиз → frontier-web.zip / frontier-<версия>.apk
```

* **Обновление игры.** В релизе лежит zip собранной игры. Оболочка скачивает его,
  распаковывает в `filesDir/www.pending`, проверяет, что внутри есть `index.html`,
  и переименовывает папки (`www` → `www.old`, `www.pending` → `www`). Перезагрузка
  страницы — и игра новая. Сохранение не теряется: и вшитая, и скачанная версии
  отдаются с одного и того же origin, поэтому localStorage не меняется.
* **Обновление оболочки.** APK скачивается в `cacheDir` и передаётся
  `PackageInstaller` — это системный установщик, он показывает единственное
  подтверждение и перезапускает приложение. Браузер не участвует. Единственное,
  что нужно один раз разрешить в настройках — «Установка неизвестных приложений»
  для FRONTIER (кнопка в карточке обновления открывает нужный экран).
* **Версии.** `version.json` в корне репозитория — источник истины: и APK
  (`versionName`/`versionCode`), и веб-бандл собираются с одним номером, поэтому
  оболочке достаточно сравнить два числа.

## Интерфейс обновления

В игре карточка **ОБНОВЛЕНИЕ** живёт в двух местах: раздел **ЛЕНТА** и раздел
**НАСТРОЙКИ** (там же меняются параметры приложения: пауза, темп времени,
анимация прыжка, подтверждения и автосохранение). В карточке — версии, кнопка
проверки, установка игры и APK, прогресс загрузки. Тихая проверка идёт при запуске
(не чаще раза в 6 часов) и, если что-то нашлось, показывает уведомление-подсказку.

## Если игра не появилась

Игра отдаётся WebView из локальных файлов, и здесь легко получить пустой экран:
ответ без MIME-типа заставляет Chromium отказаться от исполнения модуля игры
(`Failed to load module script … MIME type of ""`), и на экране остаётся только фон.
Поэтому у каждого ответа явный тип — за это отвечает `WebAssetHandler`, а тесты
фиксируют и пути, и типы. Если же что-то всё-таки сорвалось, оболочка показывает
собственную диагностику: последние сообщения страницы, ошибки загрузки и кнопку
**ОБНОВИТЬ ПРИЛОЖЕНИЕ** — свежую сборку можно поставить прямо с телефона, даже
когда игра не рисуется. Панель скрывается нажатием на текст.

## Сборка

```bash
npm run android:debug   # debug APK (быстро, для проверки на телефоне)
npm run android:apk     # release APK, подписанный ключом из keystore.properties
npm run release -- patch  # версия + сборка + релиз на GitHub с обоими ассетами
```

Требования: JDK 17+ (`JAVA_HOME`) и Android SDK с platform 36 и build-tools 36
(`ANDROID_HOME`). Скрипт `scripts/android-build.mjs` сам определяет пути и пишет
`local.properties`; существующий Gradle можно указать переменной
`FRONTIER_GRADLE`, а Maven-зеркала включить через `FRONTIER_MAVEN_MIRROR=aliyun`.

Можно собирать и напрямую:

```bash
cd android
JAVA_HOME=/path/to/jdk ./gradlew assembleRelease
./gradlew :app:testDebugUnitTest   # юнит-тесты логики обновления, без устройства
```

## Установка на телефон

```bash
adb install -r build/frontier-<версия>.apk
```

Первая установка — вручную (ADB или файл APK). Дальше обновления приходят сами:
игру оболочка меняет молча, для APK система один раз спросит подтверждение.

## Подпись

`app/frontier-release.jks` и `android/keystore.properties` лежат в репозитории
осознанно: Android не даёт обновить приложение APK с другой подписью, а FRONTIER
обновляет себя сам. Пароль там же — ключ нужен для воспроизводимых сборок.
Если ключ будет заменён, придётся один раз удалить приложение и поставить новое.

## Тесты

Логика, от которой зависит обновление, покрыта юнит-тестами без эмулятора:
сравнение версий (`VersionTest`), разбор ответа GitHub (`ReleaseInfoTest`),
распаковка и подмена бандла (`WebBundleTest`) и раздача файлов игры — пути и
MIME-типы (`WebAssetHandlerTest`). Всего 26 тестов.

```bash
cd android && ./gradlew :app:testDebugUnitTest
```
